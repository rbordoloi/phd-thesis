# PhD Thesis

## Setup

* Install and activate the conda environment with `conda create --file env.yml`
* Install [Quarto](https://quarto.org/docs/get-started/)
* Run `quarto add rchaput/acronyms`

## Editing

To render and view the pdf, run `quarto render`

For editing, using the webserver is easier and faster since it only builds individual chapters. Just run `quarto preview`.
